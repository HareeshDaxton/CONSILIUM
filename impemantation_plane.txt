================================================================================
CONSILIUM — IMPLEMENTATION PLAN
Phases P0–P14 broken into sections (3–5 per phase).
Sources of truth: AGENTS.md (invariants), ARCHITECTURE.md (build spec), SKILLS.md (playbooks).
Rules that apply to EVERY section:
  - Run the `architecture-guard` skill checklist before starting.
  - Tests come with the change, not after.
  - Default test suite: no network, no real LLM (fakes + recorded fixtures only).
  - Do not start the next section until the current one's exit check passes.
  - Anything encoding a clinical judgement gets a `# CLINICAL-REVIEW:` marker.
